# Формат коммита

> Копия канонического документа из приватного `AxiOm_Architecture`
> (`COMMIT_FORMAT.md`) — там источник правды. В публичный `AxiOm-v2`
> **не переносить**, как `ONBOARDING.md` и `REBRANDING.md`.
>
> Язык коммитов этого репозитория — **русский**.

## Кто читает коммит

Тот, кто через полгода делает `git log` или `git blame` и спрашивает: **почему это
так сделано?** Что сделано — видно в диффе, и пересказывать его незачем. Ценность
коммита в том, чего в диффе нет: какой симптом чинили, почему выбран этот путь и
что сознательно не стали делать.

## Заголовок

- **`Область: что стало`** — например `Телемост: выключение отменяет начатую
  попытку подключения`, `Android: шторка и возврат в приложение больше не рвут
  связь с ядром`, `Установщик 4.5.0: не везти старые hiddify-core.dll`.
- **Область — как её понимает человек**, а не слой кода: `Телемост`, `Ядро`,
  `Android`, `Установщик`, `docs`. Не `notifier`, не `VpnConfigRepository`.
- **Результат, а не действие.** Плохо: «исправлен баг в разборе подписки».
  Хорошо: «Подписка: звено цепочки больше не показывается отдельным сервером».
- До ~72 символов, без точки в конце.
- **Язык — по репозиторию:** журнал и `AxiOm-v2` — русский; `Tejar` — английский
  (форк англоязычного апстрима, вся история на английском). Не смешивать:
  коммит на чужом языке ломает читаемость `git log` сильнее, чем кажется.
- Релизный коммит Tejar: `Tejar <версия>: <три ключевые вещи>`.

## Тело

1. **Первый абзац — почему.** Симптом словами того, кто его видел: «Попытку никто
   не отменял: она ждала туннель до 90 с и уже после выключения ставила ошибку и
   останавливала relay — возможно, уже новой сессии». Здесь же — настоящая
   причина, если она неочевидна из диффа.
2. **Дальше список, что сделано** — по существу, а не построчно.
3. **Отдельно отметить:** неочевидные решения, то, что намеренно **не** сделано,
   и известные ограничения. Это то, что дороже всего восстанавливать потом.

Ширина ~72–76 символов. В журнале удобно ссылаться на разделы: `§8: версия в
проде 4.4.3 → 4.5.0`.

## Чего быть не должно

- **Заголовков `fix`, `update`, `wip`, `изменения`, `правки`** — они не несут
  информации и превращают `git log` в шум.
- **Пересказа диффа построчно.** Список файлов git покажет и сам.
- **Секретов** — значений ключей, паролей, токенов, а также **путей к файлам с
  секретами**. В любом репозитории, включая приватный журнал (§5 политики).
- **Устройства скрытых функций в публичных репозиториях** — там действует та же
  граница, что и для release notes (§2 политики). Коммит публичен так же, как код.

## Агентские коммиты

Коммит, сделанный агентом, заканчивается строкой:

```
Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
```

## Перед коммитом — обязательное

| Репозиторий | Проверка |
|---|---|
| **Tejar** | `git ls-files -v TMessagesProj/config/release.keystore` → должно начинаться с `S`. Без флага `skip-worktree` в публичный уедет настоящий ключ подписи — это полный захват приложения |
| **AxiOm v2** | в какой remote уйдёт: `dev` приватный, `origin` публичный. Публикация — только выборочным переносом файлов, никогда merge |
| **Журнал** | дифф на секреты перед каждым коммитом |
| **Везде** | `git status --porcelain` и коммитить **только свои файлы**. Не `git add -A` вслепую: в дереве бывают чужие правки и сгенерированные файлы |
