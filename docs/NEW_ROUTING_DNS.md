## Цель

Российские ресурсы выходят **мимо туннеля, с домашнего IP**. Разрешение имён
не зависит от одного резолвера и от скачивания `geoip-ru.srs` с GitHub.

## Этап 0 — что уже известно без живого дампа

Из реального `current-config.json` при `region=ru` (разбор 20.09):

```
route: domain_suffix .ru → direct
       rule_set geoip-ru + geosite-ru → direct
dns:   .ru / geosite-ru → dns-direct (local, ipv4_only)
       иначе → dns-remote (tcp 8.8.8.8 через select)
rule_set: качается с hiddify/hiddify-geo через download_detour=select, 120h
```

Гипотеза симптома: до первой удачной загрузки rule-set IP-уровень молчит.
Проверка на устройстве: лог загрузки `.srs`, наличие на диске, таблица 15–20 URL.

## Что делает этот PR (клиент, до форка ядра)

1. **Kill-switch** `new-routing-enabled` (дефолт `true`) — выключить новую
   логику клиента без переустановки. Пока ядро официальное, флаг управляет
   доп. правилами из Dart и UI; полный dual-DNS появится после форка.
2. **Регион** зафиксирован в `ru`: UI выбора скрыт (intro + настройки),
   миграция prefs v8 принудительно пишет `region=ru`.
3. **Доп. bypass-правила** при включённом флаге: `.ru` / `.su` / `.рф` и
   явный список RU-сервисов на зарубежных доменах (`ru_direct_domains.dart`).
4. **`resolve-destination=true`** миграцией — чтобы IP-правила ядра могли
   сработать для доменных соединений.
5. **Пресеты DNS** расширены (Google/CF/Yandex/Level3); дефолт direct = `local`.
6. **Скрипт** `scripts/build_ru_prefixes.py` — RIPE → список префиксов для
   последующей вшивки в ядро (пока не в runtime).

## Что ещё нельзя без форка ядра

- Локальный радикс RU-префиксов вместо remote `geoip-ru.srs`
- Двухплечевой DNS (гонка direct/remote + фильтр по RU IP)
- Автоблок DoH на уровне ядра
- Кэш решения домен→direct|tunnel

Исходник ядра: `https://github.com/hiddify/hiddify-core` (релиз v4.1.0).
Отдельный репозиторий форка (рабочее имя `AxiOm-core-dev`) — следующий шаг
после зелёного этапа 1.

## Критерии приёмки (напоминание)

- 15–20 URL до/после; дом / мобильный / чужой Wi‑Fi
- Android + Windows + Linux
- Отказы: мёртвый direct DNS, смена сети, недоступный GitHub geoip
- Kill-switch возвращает прежнее поведение клиента
